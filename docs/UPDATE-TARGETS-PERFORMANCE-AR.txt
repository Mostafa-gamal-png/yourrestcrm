تحديث Yourrest CRM — المستهدفات وتقييم الأداء في صفحة واحدة

الملف Yourrest-CRM-Targets-Performance-Update.zip تحديث تراكمي للسيرفر يتضمن التحديثات السابقة، ومنها بحث العملاء والتسجيل المستمر والتوقفات.

ما تغيّر:
- ملخص المناديب أعلى الصفحة يعرض المستهدف والمحقق ونسبة التحقيق والمتبقي للصنف المختار بوحدته، مع التحقيق المرجح ودرجة الأداء والمؤشرات الناقصة. اختيار الصنف في الملخص موحد بين البطاقات، ولا يجمع كميات أصناف مختلفة.
- زر «عرض التفاصيل» يختار المندوب ويفتح تفاصيله في نفس الصفحة. يتبع الملخص فلاتر الشهر والفرع والمندوب والبحث، ويتحدث بعد حفظ المستهدف أو التقييم مع الاحتفاظ بالصنف المختار.
- القيم الناقصة تبقى غير متاحة، والتقييم غير المكتمل لا يتحول إلى صفر أو درجة نهائية. في الشهر القادم يظهر المستهدف فقط دون محقق أو متبقٍ أو درجات أداء قبل بداية الفترة.
- صفحة واحدة باسم «المستهدفات وتقييم الأداء» للمشرف ومدير المبيعات ومدير النظام، بدل صفحتين في القائمة الجانبية وقائمة الموبايل.
- يظهر قسم المستهدفات وقسم تقييم الأداء معًا، مع اختيار موحد للشهر والفرع والمندوب والبحث. يمكن الانتقال مباشرة بين القسمين داخل الصفحة.
- «كل الفروع» يعرض البيانات المسموح بها للحساب. اختر فرعًا لعرض مستهدف الفرع وفرق التوزيع؛ مستهدف المدير والمشرف يظل محسوبًا من الفريق وفق القواعد الحالية.
- بعد حفظ مستهدف أو تقييم، تتحدث بيانات القسمين من نفس المصدر.
- يمكن تخطيط مستهدفات الشهور القادمة؛ تقييم الأداء وتصديره متاحان للشهر الحالي والشهور السابقة.
- الرابط القديم #reports يُحوّل الإدارة إلى #targets. المندوب يظل يرى «مستهدفي» فقط دون تقييم الفريق أو مبيعاته أو صلاحية تعديل المستهدف.
- لم تتغير معادلات KPI أو أوزانه أو صلاحيات الحفظ أو نطاق الفريق والمنطقة. المشرف يطّلع؛ تعديل المستهدفات وتقييم الإدارة يظلان وفق الصلاحيات الحالية.

رفع التحديث:
1. في cPanel → Setup Node.js App اختر تطبيق crm.yourrest.org واضغط Stop App قبل فك الملفات.
2. ارفع ZIP وافكّه داخل /home/youriedx/yourrest-crm مع استبدال الملفات المتطابقة في release. يكون release بجوار app.cjs الموجود مباشرة.
3. اضغط Start App ثم أعد فتح التطبيق.

لا تفك التحديث داخل /home/youriedx/crm.yourrest.org. لا تشغّل setup.cjs أو npm install للتحديث، ولا تستبدل settings.cjs أو مجلد البيانات /home/youriedx/yourrest-crm-data أو رابط node_modules الخاص بـcPanel.
الحزمة تحتوي release ودليل التحديث فقط؛ لا تحتوي بيانات بداية أو قاعدة بيانات عمل أو إعدادات خاصة.

أندرويد وقاعدة البيانات:
لا يوجد تغيير أندرويد أو ترحيل قاعدة بيانات جديد لهذا الدمج. الحزمة تتضمن أندرويد 1.0.2 (versionCode 3) نفسه من تحديث التسجيل المستمر. إذا كان مثبتًا، يكفي تحديث السيرفر وإعادة فتح التطبيق.
إذا لم تركّب تحديث التسجيل المستمر السابق، اتبع UPDATE-CONTINUOUS-TRACKING-AR.txt في المصدر الكامل، وثبّت APK1.0.2 فوق القديم وفعّل الأذونات مرة أولى. دمج الصفحتين يعمل من تحديث السيرفر؛ جمع GPS في الخلفية يحتاج نسخة أندرويد الأصلية والأذونات السابقة.

التحقق بعد الرفع:
- افتح حساب مدير أو مشرف وتأكد أن القائمة تحتوي صفحة واحدة فقط وأن الشهر والمندوب والفرع يطابقون القسمين.
- غيّر الصنف المعروض، وراجع اختلاف الوحدة والمستهدف والمحقق والمتبقي، ثم افتح تفاصيل أحد المناديب من بطاقة الملخص.
- كمدير مخوّل، احفظ مستهدفًا وراجع تحديث الملخص ونسبة التحقيق مع بقاء الصنف المختار، واحفظ تقييم الإدارة ثم تحقق من ظهوره والمؤشرات المتبقية.
- افتح شهرًا قادمًا: تظهر المستهدفات دون درجات تقييم مستقبلية.
- افتح حساب مندوب: يظهر مستهدفه الشخصي فقط، ولا يظهر تقييم الفريق أو أدوات تعديل المستهدفات.
- راجع العرض بالعربية والإنجليزية وعلى الموبايل.

الاختبارات الآلية موثقة في VERIFICATION.json بالنسخة الكاملة. لم يُنشر هذا التحديث على الاستضافة أو يُختبر على هاتف فعلي في هذه المحاولة.
