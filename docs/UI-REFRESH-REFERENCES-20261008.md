# Yourrest UI refresh reference

This release adapts the approved Yourrest green UI using lightweight SVG and CSS.
No Three.js, WebGL, animation framework, demo business records, fonts, remote
thumbnails or video assets are added to the application.

Visual references supplied by the user:
- https://github.com/MengTo/threeui
- https://threeui.com/css/performance-gauges
- https://threeui.com/css/uplink-loader
- https://threeui.com/ui-elements/skeuomorphic-toggle/modern
- https://threeui.com/buttons/rectangle-buttons/gradient-pill-button

ThreeUI Community code is MIT, copyright 2026 Meng To. The implementation here
uses existing Yourrest components and original CSS/SVG inspired by those visual
patterns; it does not import the ThreeUI package or redistribute preview assets.
Existing Yourrest dependency licenses remain applicable.

The source reference repository excludes paid Pro/Beta components from its
Community catalog. No restricted component source was accessed.
